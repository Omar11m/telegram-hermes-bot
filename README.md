# Telegram Hermes Bot 🤖

بوت تيليجرام ذكي متعدد الوسائط يدمج بين:
1. **المعالجة النصية المحلية**: باستخدام نموذج **Hermes 3 (3B)** عبر **Ollama** على كرت الشاشة بدون الحاجة لأي مفاتيح API أو اتصال سحابي.
2. **المعالجة الصوتية الذكية**: معالجة الرسائل الصوتية (Voice Messages) وفهم اللغة العربية الفصحى واللهجات عبر **Google Gemini Multimodal Audio**.
3. **الذاكرة المستمرة**: حفظ سياق المحادثات لكل مستخدم داخل `memory.json`.

---

## الميزات الرئيسية

- 💬 **محادثات نصية ذكية**: مدعومة بنموذج هيرمز 3 المحلي مع تعليمات صارمة للالتزام بالعربية الفصحى.
- 🎙️ **دعم الرسائل الصوتية**: استماع وتحليل الملاحظات الصوتية والملفات الصوتية عبر Gemini والرد عليها نصياً.
- 🧠 **ذاكرة محادثة لكل مستخدم**: حفظ وتحديث السجل تلقائياً في `memory.json`.
- ⚡ **أوامر سريعة**:
  - `/start` - بدء المحادثة والتعريف بالبوت.
  - `/reset` أو `/clear` - تصفير الذاكرة والبدء من جديد.

---

## متطلبات التشغيل

```bash
pip install -r requirements.txt
```

---

## التشغيل

1. تأكد من تشغيل Ollama ونموذج Hermes:
```bash
ollama run hermes3:3b
```

2. شغّل البوت:
```bash
python telegram_bot.py
```
