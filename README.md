# Telegram Hermes Bot 🤖🔒

بوت تيليجرام ذكي متعدد الوسائط يدمج بين الذكاء المحلي والسحابي مع **منظومة أمان وتشفير متقدمة**:
1. **المعالجة النصية المحلية**: باستخدام نموذج **Hermes 3 (3B)** عبر **Ollama** محلياً على كرت الشاشة بدون مفاتيح API أو اتصال خارجي.
2. **المعالجة الصوتية الذكية**: معالجة الرسائل الصوتية (Voice Messages) وفهم اللغة العربية الفصحى واللهجات عبر **Google Gemini Multimodal Audio**.
3. **تشفير البيانات في وضع السكون (Data at Rest Encryption)**: تشفير سجلات المحادثة والذاكرة بالكامل عبر **AES-128 / Fernet** داخل ملف مشفر `memory.enc`.
4. **حماية الخصوصية ومكافحة الإغراق**: حذف التسجيلات الصوتية فوراً بعد معالجتها، وتحديد معدل الطلبات (Rate Limiting)، وتقييد الوصول (Whitelist).

---

## الميزات الأمنية المطبقة 🛡️

- 🔑 **عزل المفاتيح والتوكنات**: تُدار المفاتيح السرية حصرياً عبر ملف `.env` المحجوب تماماً عن مستودع Git.
- 🔒 **تشفير سجلات المحادثة**: حفظ الذاكرة بصيغة مشفرة (`memory.enc`) لا يمكن قراءتها من أي طرف خارجي.
- 🧹 **التنظيف الآمن للصوتيات**: إتلاف وحذف أي ملف صوتي مستلم فور الانتهاء من معالجته لضمان سرية صوت المستخدمين.
- 🚦 **مكافحة الإغراق (Rate Limiting)**: حماية البوت من إرسال كميات هائلة من الرسائل المتتالية.
- 👤 **قائمة الوصول المصرح بها (Access Whitelist)**: إمكانية حصر التحدث مع البوت على معرفات محددة عبر `ALLOWED_USER_IDS` في `.env`.
- 🧼 **تعتيم السجلات (Log Sanitization)**: إخفاء وتعتيم نصوص الرسائل في شاشة الطرفية لعدم كشف الأسرار.
- 🚫 **تطهير سجل Git (Zero Leak)**: سجل المستودع نظيف 100% ولا يحتوي على أي توكن تاريخي.

## متطلبات التشغيل

```bash
pip install -r requirements.txt
```

---

## إعداد ملف البيئة `.env`

انسخ الملف التوضيحي وضع مفاتيحك الخاصة:
```bash
cp .env.example .env
```
محتوى `.env`:
```env
TELEGRAM_BOT_TOKEN="توكن_البوت_من_BotFather"
GEMINI_API_KEY="مفتاح_gemini_api"
SECRET_ENCRYPTION_KEY="مفتاح_تشفير_fernet_يُولد_تلقائياً"
ALLOWED_USER_IDS="all" # أو ضع معرفك مثلاً: 12345678,87654321
```

---

## التشغيل

1. شغّل Ollama ونموذج Hermes (إن لم يكن قيد التشغيل بالفعل):
```bash
ollama serve
```

2. شغّل البوت الآمن:
```bash
python telegram_bot.py
```
